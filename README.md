# Taichung City Delivery Driver Traffic Accidents Dashboard

Interactive open data analytics dashboard analyzing traffic accidents involving food and courier delivery drivers in Taichung City from 2022 Q3 to 2026 Q2 (16 quarters).

## Live Dashboard
👉 **[View Live Dashboard](https://nutcelvischen-jpg.github.io/taichung-delivery-dashboard/)**

## Features
- **Trend Analysis (2022 - 2026)**: Multi-series SVG time-series curves with hover tooltips and category comparisons.
- **Year Filter Selector**: Toggle individual years or examine the entire 2022-2026 period.
- **Category Focus Filter**: Analyze Category A1 (Fatal), A2 (Injury), A3 (Property Damage), or total casualties.
- **Severity Breakdown Donut Chart**: Real-time proportion calculations.
- **Interactive Data Table**: Sortable columns, search bar, and one-click CSV export.

## Data Source
- **Taichung City Open Data Platform (臺中市政府資料開放平臺)**
- **Publishing Agency**: Taichung City Police Department (臺中市政府警察局)
